# Energy Twin - Project Structure

A React application for energy insights and digital twin visualization.

## Project Name
**energy-twin** - A concise name representing "Energy Insights Digital Twin"

## Directory Structure

```
energy-twin/
├── backend/                 # Backend implementation (placeholder)
├── public/                  # Public assets
│   └── static/             # Static files (images, fonts, etc.)
├── src/                    # Source code
│   ├── components/         # React components
│   ├── services/           # API services
│   ├── helpers/            # Helper functions
│   ├── utils/              # Utility functions
│   ├── hooks/              # Custom React hooks
│   ├── context/            # React Context providers
│   ├── constants/          # Application constants
│   ├── assets/             # Assets (images, icons)
│   └── styles/             # Global styles
├── package.json
└── README.md
```

## Getting Started

### Install Dependencies
```bash
npm install
```

### Development Server
```bash
npm start
```

### Build for Production
```bash
npm run build
```

### Run Tests
```bash
npm test
```

## Folder Descriptions

- **backend/**: Placeholder for backend API implementation
- **public/static/**: Static assets served directly
- **src/components/**: Reusable React components and page components
- **src/services/**: API integration and data fetching logic
- **src/helpers/**: Helper functions for data manipulation and validation
- **src/utils/**: General utility functions
- **src/hooks/**: Custom React hooks for shared logic
- **src/context/**: Global state management using React Context
- **src/constants/**: Application-wide constants and configuration
- **src/assets/**: Images, icons, and other media files
- **src/styles/**: Global CSS/SCSS files
